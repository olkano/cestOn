Start using cestOn

See your recent conversations and keep the details you want to carry into tomorrow.

On your Windows PC

  1. Install Node.js 24 for Windows if you need it.
  2. Extract the cestOn ZIP. Double-click Start-cestOn.cmd from the extracted folder.
  3. Choose whether to connect local Codex and Claude history. In your browser, paste the one-use code shown in the terminal and choose Connect device.

Open the same launcher after a restart. You can open cestOn in your PC browser while it is running.

Pick up your work

  • Chats shows saved Codex and Claude conversations with their titles. The clock shows when a chat last finished or when the folder last had a conversation. Working shows a confirmed run. Likely working means recent activity suggests the turn is still open. New saved messages appear as you watch. Open a chat, type in Your reply and choose Send. If the provider has that conversation open elsewhere, close it there and try again. Use Work to request file changes.
  • Memory is where you save something worth keeping. Start with any text. Add a project link, importance or date when it helps. Edit a note when things change or choose Forget note to remove it.
  • New conversation in Chats opens General. Try Remember: check the deployment notes on Friday. Find it again in Memory. You can reopen earlier General conversations from Chats.

Use another device

On this PC, open the browser’s install option or the install help in cestOn. On a phone, use your installation’s dedicated HTTPS address, then pair the phone with a fresh code from the PC. The printed loopback address works on the PC itself. The PC needs to stay awake and connected for the phone to reach it.

To set up phone connectivity or configure a managed agent, see the host setup guide in the extracted bundle.

If setup stops

Run the launcher from a regular Windows account. If the port is already in use, stop the app using it or follow the host setup guide to choose another port. If the browser opens but pairing fails, reopen the launcher to get a fresh code.
