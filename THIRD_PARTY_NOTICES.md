# Third-party notices

The lockfile records exact dependency versions and integrity references. Each local bundle contains the selected production dependency sources, their distributed license/notice files and a generated `dependency-notices.json` inventory with name, version, declared license and package path. Missing or ambiguous license declarations require review before redistribution.

Development tools remain source dependencies and are installed independently for verification. Their licenses are available with their packages. The bundle does not copy installed Codex, Claude Code or cestDone runtimes, their authentication, private source or operator configuration. Operators supply those executables separately under their applicable terms.

The supplied cestOn SVG is the master icon and generated PNGs derive from it. This repository declares the application `UNLICENSED`; dependency licenses do not grant an application license. The repository owner must resolve application/icon rights and select a license before public package distribution.
