The operating model

Use cestOn to set priorities, get a briefing, and direct work. Keep VS Code for inspecting and editing code. Your phone controls the same tasks on the connected PC; it does not need its own code checkout.

A proposed experience, not a connected product

Buttons change only this local demonstration. Voice, notifications, agent responses, permissions, and connection changes are simulated. No microphone, account, repository, or external system is accessed. Refreshing clears the demo.

The implementation specifications define the intended behavior and required verification. This prototype is illustrative and performs no agent execution, installation, or update.
